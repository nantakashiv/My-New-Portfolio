ATM Monitoring Web System

🏢 PT Collega Inti Pratama (Telkom Group)
📅 February 2024 – May 2024
🎯 Jr. Programmer
Vue.js Spring Boot PostgreSQL RESTful API Figma Postman Auth & Authorization

Project Overview

This project was built during my internship at PT Collega Inti Pratama to address a real operational need: a centralized, web-based system to monitor ATM disturbances and track repair progress in real time. Prior to this system, disturbance reports were handled manually, which led to delays and reduced operational efficiency.

As the Jr. Programmer, I was involved in every stage of the development process — from UI/UX design in Figma, through frontend development in Vue.js, to backend API development using Spring Boot. I also designed the PostgreSQL database schema and implemented the authentication system.

Key Features Delivered

  • Real-time ATM disturbance tracking dashboard with status updates and repair workflow management for operational teams.
  • RESTful API backend built with Spring Boot, handling disturbance reports, status updates, and user management with proper authentication and authorization.
  • PostgreSQL database architecture designed for efficient storage and retrieval of ATM event data, disturbance logs, and repair records.
  • Responsive, intuitive Vue.js frontend designed for daily operational use by non-technical staff.

Technical Highlights

Designed the system architecture to cleanly separate concerns between the frontend (Vue.js SPA), the API layer (Spring Boot REST), and the data layer (PostgreSQL). Conducted thorough API testing using Postman to identify bugs, validate endpoints, and ensure system reliability before deployment. Designed clean data flows with role-based access control to protect sensitive system functions.

Technology Stack

🟩 Vue.js ☕ Java / Spring Boot 🐘 PostgreSQL 🔌 RESTful API 🎨 Figma 📬 Postman 🔐 Auth & Authorization
